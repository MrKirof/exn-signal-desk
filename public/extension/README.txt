Desk collector for the Windows desktop app.
Read-only. It does not click buy or sell.

1. Install and open the desktop app first. It listens on http://127.0.0.1:8090.
2. Unzip this folder. Chrome → Extensions → Developer mode → Load unpacked → the exn-collector folder.
3. Paste http://127.0.0.1:8090 and the token shown in the desktop app. Save and test.
4. Open the Exness terminal on EURUSD, GBPUSD, USDJPY, XAUUSD, or BTCUSD and keep that tab active.

The app stores candles on this PC. It does not use a hosted database and it does not place an order.
