============================================================
A. TOMAR CONCEPT (jeita tumi banate cheyechile)
============================================================

1. Product ki
- Windows desktop app (.exe), hosted website na.
- Sathe akta Chrome Manifest V3 extension.
- Target broker: Exness.
- App trade place korbe na. Buy/Sell click korbe na. Order API connect korbe na.
- App sudhu market dekhe signal dibe. Trade tumi nijei Exness terminal e nibe.

2. Signal ki dibe
- Candle close howar por direction: LONG / SHORT / WAIT.
- Per trade roughly 10-30 minute.
- Target example: 10 tar moddhe 8 ta profit. Eita example, measured result na.
- Signal er sathe thakbe: entry, stop, target, karon, invalidation.
- Buy hole Ask. Sell hole Bid. Spread hisab e thakbe.

3. Analysis e ki thakbe (tomar kotha onujayi)
- Closed candle + candlestick pattern
- Support / resistance
- Multi-timeframe: 1H, 15M, 5M. Tin tai same dike hole strong.
- SMC: Order Block, Fair Value Gap (FVG), Liquidity zone
- ATR diye volatility + koto dur move howar kotha
- Nearest S/R ke target
- Fibonacci extension (1.618)
- Hybrid target:
  L1 conservative = ATR x 1.0 + nearest minor S/R
  L2 standard = Fib 1.618 / daily high-low
  L3 maximum = higher TF order block
- UI te LONG = green projection, SHORT = red projection
- Live price move hole projection bar update
- Market filter: ATR onek high ba high-impact news hole High Risk - Avoid
- News / sentiment warning
- Risk calculator: balance + risk % + SL distance = lot size
- 3 ta loss por por hole warning (revenge trading bondho)
- Multi-pair radar / heatmap
- Win/Loss mark kore condition save
- Purono candle history rekhe notun close candle er sathe compare

4. Data kivabe asbe
- Exness web terminal Chrome e khola thakbe.
- Extension read-only capture korbe. Order dibe na.
- Candle desktop app e pathabe: 127.0.0.1:8090
- App local SQLite (tape.sqlite, WAL) te rakhbe.
- Live tick age memory te, disk e batch write.
- Public / demo / fixture / Exness data alada label.
- Live Exness label taboi, jokhon asol Exness page er closed candle symbol + timeframe + timestamp + OHLC mile.
- Fixture ke Live Exness bola jabe na.

5. UI
- English
- Dark professional terminal
- Age blackhole-galaxy theme chaowa hoyechilo
- Pore control-center: bam e confirmation matrix, majhe main signal + projection, dan e SMC, niche price tape, risk calculator
- Chart lagless hote hobe
- Extension icon e mini dashboard popup

6. Packaging
- Akta portable EXE
- Alada extension zip
- Replit / hosted site dorkar nai
- GitHub sudhu source + download. Runtime na.

7. Pore extra ja chaowa hoyechilo (build hoy nai)
- Order flow / Footprint / DOM
- Transformer / RL / PyTorch trained model
- AMD GPU inference
- Cloud-hybrid backend
- Statistical arbitrage / pair mean-reversion live two-feed
Eigula chat e ask kora hoyechilo. Implementation e bose nai.

Architecture:
Chrome Exness tab -> MV3 extension (read-only) -> http://127.0.0.1:8090 (EXE khola thakle) -> memory quote + tape.sqlite -> window JS signal engine -> LONG / SHORT / WAIT

Local token (4.3.3):
exn_local_9c2e7a41b6d84f0e8a1c5d73e0b64f2a
Empty token reject.
Bind: 127.0.0.1 only.

Storage:
%APPDATA%\EXN Signal Lab\desk-data\tape.sqlite
WAL, batch ~15s, synchronous NORMAL.

Python backend nai. Port 8000 nai. Cloud nai. Trained model nai.

Signal engine (deterministic):
- closed candle only
- MTF bucket from existing bars
- SMC if bars allow
- ATR + S/R + fib targets (measured, probability na)
- risk lot size (order pathay na)
- radar = jei pair e feed ase
- mean stretch = last close vs mean
- depth = bid/ask thakle; lot ladder nai

Flag:
EXNESS_BROWSER_CAPTURE_VERIFIED = false
Live Exness label on kora hoy nai.
